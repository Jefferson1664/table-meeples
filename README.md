# Table Meeples V3
PWA pour gérer des jeux personnalisés, réserves, composants groupés et tables multiples.

Installation GitHub Pages : remplacer `index.html`, `manifest.webmanifest`, `sw.js` et `icon.svg` par ceux de cette version.

La V3 utilise une nouvelle clé de stockage (`tableMeeplesV3Data`) : aucun ancien jeu V2, notamment Paladins, n'est repris automatiquement.
