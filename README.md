# Table Meeples V2

PWA mobile pour simuler des réserves et une table de jeu.
- Groupes automatiquement regroupés par composant
- Déplacement de groupes entiers entre zones
- Réserve avec quantités disponibles
- Jusqu’à 15 couleurs de meeples
- Ajout de composants personnalisés
- Plusieurs jeux et zones
- Sauvegarde locale et fonctionnement hors-ligne après premier chargement

Déployer les fichiers à la racine d’un hébergement HTTPS (ex. GitHub Pages), puis Safari > Partager > Ajouter à l’écran d’accueil.
