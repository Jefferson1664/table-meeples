# Table Meeples — PWA

Cette version ne nécessite pas de Mac ni Xcode.

## Installation sur iPhone

Une PWA doit être servie depuis une adresse HTTPS (ou localhost pour le développement). Le plus simple est de publier le contenu de ce dossier sur un hébergement statique HTTPS.

Ensuite, sur l'iPhone :
1. Ouvrir l'adresse dans Safari.
2. Appuyer sur Partager.
3. Choisir « Sur l'écran d'accueil ».
4. Ouvrir l'icône Table Meeples.

Les données sont conservées localement dans le navigateur.

## Contenu

- Paladins du Royaume de l’Ouest préchargé
- Meeples jaune, noir, rouge, bleu clair, brun
- Pain
- Monnaie argentée
- Réserve
- Table regroupée par type
- Création de jeux
- Création de composants
- Réinitialisation de la table
- Fonctionnement hors ligne après le premier chargement

Pour une version publiable sur l'App Store, il faudra ensuite une chaîne de build/signature Apple ou un service de build iOS.
